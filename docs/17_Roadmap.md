## 阶段 1：基础框架 ✅

**目标**：两人能连接成功

**已完成**：
- 启动器：建房/加入/房间码/准备/存档同步
- 网络层：TCP 7655 + 44 字节帧协议 + CRC
- 大厅：成员列表/房间码/准备状态
- 心跳：5s 间隔，15s 超时

**验证**：v92-v913 虚拟测试（150+ 断言）

## 阶段 2：时间同步 ✅

**目标**：Pause/Play/Speed 同步

**已完成**：
- `clock_sync.py`：监控时间速度变化
- 暂停/播放/1x/2x/3x 全同步
- 循环检测（本端变化不广播回来）

**验证**：v99 虚拟测试（12 断言）

## 阶段 3：Sim 同步 ✅

**目标**：位置/旋转/动画同步

**已完成**：
- `sync.py`：每 0.2-0.5s 广播 Sim 位置
- 插值平滑（delta 累积）
- 回环抑制（发自己位置不给回来）
- 自适应频率（根据网络延迟）

**验证**：v95 虚拟测试（18 断言）

## 阶段 4：交互队列 ✅

**目标**：做饭/睡觉/社交/工作

**已完成**：
- `interaction_sync.py`：监听 `push_super_affordance`
- 对端执行相同交互（`sim.push_super_affordance`）
- 3s 回环抑制窗口

**验证**：v917 虚拟测试（B 段 6 断言）⚠️ 真机待验证

## 阶段 5：对象同步 🟡

**目标**：冰箱/沙发/电脑 + 对象锁

**已完成**：
- 背包物品同步（`inventory_sync.py`）
- 关系同步（`relationship_sync.py`）

**待做**：
- 对象锁（A 和 B 同时抢同一个冰箱 → 服务器仲裁）
- 研究：Minecraft 1.20.2+ 才加 server-authoritative-block-breaking——对象级互斥成本高，暂缓

## 阶段 6：Build/Buy ✅

**目标**：家具放置/删除/移动

**已完成**：
- `buy_sync.py`：监听 Buy 模式家具放置
- 家具类同步（Floor/Wall/Stairs 过滤）
- 位置/旋转/物体 ID 广播

**验证**：v917 虚拟测试（D 段 4 断言）⚠️ 真机待验证

## 阶段 7：存档同步 ✅

**目标**：Save Hash + 自动下载 + 备份

**已完成**：
- 启动器存档同步：base64 分块（64KB）→ SHA256 校验
- 游戏内 save 同步：host 为唯一保存者
- 备份：写入前自动 .bak 备份

**验证**：v915 虚拟测试（18 断言）+ v918 端到端

## 阶段 8：优化 🟡

**目标**：压缩/增量/重连/断线恢复

**已完成**：
- 断线检测：30s 超时 → 清理 + 广播
- 启动器房间清理：离开 → 自动移除成员

**待做**：
- 增量同步（只发变化 delta）
- 消息压缩（gzip/zstd）
- 自动重连（指数退避 + jitter）
- Interest Management（只同步视野内对象）
- 自动更新（启动器检查新版本）
