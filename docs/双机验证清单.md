## 第 1 步：启动器房间流程（不启动游戏！）

### 房主（sora）
1. 打开启动器 → 点「创建房间」→ 记下**房间码**（6 位）和你的 IP（192.168.0.112）
2. 等待朋友加入（房间页应显示 2 人）

### 朋友
1. 打开启动器 → 点「加入房间」→ 输入房间码（或点🔍扫描自动填）
2. 如房间有密码 → 输入密码
3. 加入成功后应看到房主名字

### ✅ 验证点
- [ ] 房主看到朋友名字出现在成员列表
- [ ] 朋友看到房主名字
- [ ] 扫描按钮能找到房间（🔒 表示有密码）

## 第 2 步：准备 + 存档同步

1. 双方点「准备」（全员准备后房主可点开始）
2. 房主点「同步存档」→ 存档分块传输给朋友
3. 朋友端看到同步进度 → 完成后显示 ✓

### ✅ 验证点
- [ ] 同步完成后双方存档一致
- [ ] 房主确认朋友已 ready

## 第 3 步：开始游戏

1. 房主点「开始游戏」→ 双方启动器自动拉起模拟人生4
2. 游戏加载完成 → 打开作弊控制台（Ctrl+Shift+C）

## 第 4 步：游戏内联机验证（按顺序）

### 4.1 连接层
| 命令 | 预期 | 房主 | 朋友 |
|:-----|:-----|:----:|:----:|
| `mp_self` | 返回 sim_id（16-18 位数字）| | |
| `mp_host`（房主）| `server listening on :7655` | | |
| 等 5 秒 | 朋友日志出现 `connected to <房主IP>:7655` | | |

### 4.2 同步验证（核心）
| 项 | 操作 | 预期 |
|:---|:-----|:-----|
| 位置 | 两人各操作小人移动 | 对方视野里小人跟着动 |
| 时钟 | 观察游戏时间 | 双方时钟一致（快进同时生效）|
| 金钱 | 房主 `money 999999` | 朋友金钱也变 |
| 交互 | A 让小人去洗澡 | B 看到 A 的小人在浴室 |
| 背包 | A 捡起物品 | B 看到 A 手里/背包变化 |
| 关系 | A 和 NPC 交谈 | B 看到 A 的关系条变化 |

### 4.3 断线重连
- [ ] 朋友关游戏重开 → 重新 `mp_connect` 能连上
- [ ] 房主关游戏重开 → 朋友自动重连或手动重连

## ⚠️ 已知限制（如实告知朋友）

- **位置同步有延迟**（10Hz 快照，约 100ms）——快速移动可能看到轻微"瞬移"
- **不做 build-mode 同步**——建房模式各管各的
- **存档同步只在启动器做**——游戏内改动不实时回写对方存档
- 双机同时操作同一个物品可能冲突（物品互斥暂缓）
