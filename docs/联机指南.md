# Sims4 局域网联机指南（v9.18）

## 前提

两台电脑都在**同一局域网**（连同一个路由器 / 同一个 WiFi），能互相 ping 通。

---

## 第一步：安装 Mod（两台都要做）

1. 桌面找到 `Sims4联机mod-v9.18-分享版.zip`
2. 解压 → 双击 `安装mod.bat`
3. 打开游戏一次，确认加载 → 退出

---

## 第二步：确认 IP（两台都要做）

**房主**需要知道自己的 IP 告诉朋友。

```bash
# Windows 终端
ipconfig | findstr "192.168"
```

输出类似 `192.168.0.112`——这就是房主 IP。

---

## 第三步：房主创建房间

1. 打开 `启动联机\启动联机.exe`
2. 「玩家名」填昵称（如"小明"）
3. 选 **🏠 房主（创建房间）**
4. 点 **🚀 创建房间**

> ⚠️ **游戏不会启动**——这是正确的。启动器会显示 6 位房间码。

5. 把 **房间码 + 你的 IP** 告诉朋友（微信/QQ）

---

## 第四步：朋友加入房间

1. 朋友打开 `启动联机\启动联机.exe`
2. 「玩家名」填昵称（如"小红"）
3. 选 **💻 加入（连接房主）**
4. 「房主 IP」填房主的 IP（如 `192.168.0.112`）
5. 「房间码」填房主给的 6 位码
6. 点 **🚀 加入房间**

> 成功加入后，双方房间页都会显示对方名字。

---

## 第五步：准备 + 存档同步

1. 双方点 **✅ 我准备**（房主已自动准备）
2. 全员准备后，房主点 **📦 同步存档**
3. 在弹窗中选存档文件（默认在 `文档\Electronic Arts\The Sims 4\Saves\`）
4. 等待进度条完成 → 状态变"存档同步完成 ✅"

---

## 第六步：开始游戏

1. 房主点 **🚀 开始游戏**
2. **双方游戏同时启动**（约 20-40 秒）
3. 进入家庭后，mod 会自动连接

---

## 验证联机成功

游戏内打开控制台（`Ctrl+Shift+C`），输入：

```
mp_debug
```

看日志是否显示 `connected`。

然后让一方移动小人——另一方屏幕上应该看到同一个小人在移动。

---

## 常见问题

### 朋友连不上房间（"连接失败"）

**防火墙**：
```bash
# 两台电脑都执行
netsh advfirewall firewall add rule name="SimSync" dir=in action=allow protocol=TCP localport=7660,7655
```

**端口被占用**：先关掉已运行的启动器，重试。

### 游戏启动后 mod 没加载

检查 `文档\Electronic Arts\The Sims 4\Mods\` 下是否有 `Sims4Multiplayer.ts4script`。

游戏设置 → 其他 → 勾选「启用自订内容与模组」和「已允许脚本模组」。

### 游戏内连不上

游戏内控制台输入：
```
mp_apply
```

手动触发连接。

### 杀软拦截启动器

把 `启动联机` 文件夹添加到杀软白名单（Windows Defender 为例）：
设置 → 更新和安全 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 添加排除项 → 文件夹 → 选 `启动联机` 文件夹。
